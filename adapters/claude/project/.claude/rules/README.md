# `.claude/rules/` — 경로 조건부 함정 인덱스

프로젝트 `CLAUDE.md` 는 모든 세션의 베이스라인 컨텍스트에 실린다. 함정 인덱스가 거기서 자라면
autocompact 헤드룸이 줄고, 대부분의 세션은 자기와 무관한 도메인의 함정을 읽는다.
그래서 **파일에 묶인 함정**은 이 디렉터리의 `paths:` 조건부 규칙 파일로 분리한다.

## 컨벤션

- **파일명**: `pitfalls-<도메인>.md` — 도메인은 소문자 한 단어(`db`·`http`·`ci`·`testing`·`infra` …).
  한 도메인에 파일 하나. 도메인은 «어느 파일을 만질 때 밟는가»로 고른다.
- **frontmatter**: `paths:` 글롭 목록만. 그 경로의 파일을 이 세션이 **`Read` 했을 때만** 파일이 실린다.
  ```
  ---
  paths:
    - "src/db/**"
    - "**/*.sql"
  ---
  ```
- **본문**: 제목 한 줄 + 인용 블록(출처·상세 위치) + 함정 **한 줄씩**(`- **무엇을 하면** → 무엇이 죽는지 (실측 날짜)`).
  상세·재현 절차·에러 문자열은 `docs/phases/PITFALLS.md` 에 두고, 줄의 문구로 검색한다.
- **CLAUDE.md 에 남기는 상시 함정은 5줄 이내**로 유지한다 — 남길 것은 ① 위임·프로세스·판정 ② 지시서를 쓸 때·task 를 나눌 때
  필요한 것 ③ 파일을 읽지 않고 **명령만으로 밟는 것** ④ 실자금·파괴적 결과. 나머지는 전부 여기로.
- **은퇴 규칙**은 `CLAUDE.md` 와 같다 — 테스트·CI·스크립트·타입으로 기계 차단되면 줄을 지우고 `PITFALLS.md` 항목 끝에
  `가드: <파일:줄 또는 테스트명>` 을 적는다.

## 실측 근거

- `paths:` 조건부 로드는 대화형 세션뿐 아니라 **헤드리스 `claude -p` 에서도 동작한다**(2026-09-19 실측, claude 2.1.277 —
  맞는 파일을 `Read` 한 뒤에만 실리고, 규칙 파일의 출처 경로가 인용된다). 한 저장소는 인덱스 51줄을 7파일로 옮겨
  베이스라인 컨텍스트를 약 30% 줄였다.
- 🔴 **`git diff`·`git show` 로만 리뷰하면 하나도 안 실린다.** 리뷰 전에 해당 도메인 파일을 하나 `Read` 하라 —
  리뷰어 서브에이전트 프롬프트에도 이 줄을 넣는다.
- 예시는 `pitfalls-example.md` — 도메인을 정하면 파일명·`paths:`·본문을 바꿔 쓰고, 예시 파일은 지운다.
